# AGENTS.md – Study-room booking (example from the Week 10 slides)

## Before you start
- Read the story and its acceptance criteria in docs/stories/.
- Business rules live in booking_service.py; reuse helpers in utils.py.

## Testing rules
- Never modify or delete existing tests to make them pass.
- If an existing test looks wrong, stop and explain why in the PR.
- Every acceptance criterion needs at least one test.
- Run `pytest -q` before opening a PR.
